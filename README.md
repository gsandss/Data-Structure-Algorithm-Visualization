# Data-Structure-Algorithm-Visualization

Education platform that visualizes key data structures and algorithms. This is a full stack project built using React and JavaScript.



[Open the live DSA Visualizer](https://gsandss-dsa.vercel.app/)

## Run and deploy

Use Node.js 24. From `frontend/`, run `npm ci` and `npm run dev`.
Use `npm run build` followed by `npm run preview` to test the production build.

On Vercel, import this repository, set the root directory to `frontend`, and use
the Vite preset. The output directory is `dist`. No environment variables are
required. Each browser keeps its own sorting state and uses the same step
functions as the Express API.

To use the API locally, run `npm ci` and `npm start` in `backend/`, set
`VITE_API_BASE=http://localhost:4000` in `frontend/.env.local`, and restart Vite.
